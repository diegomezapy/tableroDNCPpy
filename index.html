1. Fundamento bayesiano

            
Bayes permite actualizar una creencia inicial con datos observados. En notacion general:

            
P(theta | datos) = P(datos | theta) P(theta) / P(datos)

            
En esta app, theta representa el comportamiento latente del precio o de la concentracion. La salida no es una certeza, sino una distribucion posterior: una forma cuantificada de incertidumbre despues de observar los datos.

            
    
              
  • Prior: punto de partida conservador; para precios, parte de que el ratio deberia estar cerca de 1.
    • 
              
  • Verosimilitud: evidencia observada en compras, montos, unidades y pares comparables.
    • 
              
  • Posterior: resultado actualizado que se usa para priorizar revision.
    • 
            

          


          

            
2. Referencia comparable de precio

            
Antes del modelo bayesiano se construye una referencia. El error mas peligroso es comparar bienes distintos: maquinaria completa contra repuestos, metros cuadrados contra unidades, o servicios con alcances diferentes.

            
referencia(codigo, unidad) = mediana entre entidades del precio observado comparable

            
La referencia se calcula por codigo_catalogo y unidad, priorizando mediana entre entidades para reducir el peso de una entidad con muchas compras pequenas.

          


          

            
3. Ratio observado

            
El primer indicador interpretable es el ratio:

            
r_i = precio_observado_i / referencia_i

            
Un ratio de 1,00x indica precio similar a la referencia. Un ratio de 1,50x indica que el precio observado es 50% mayor que la referencia comparable. La app usa escala logaritmica porque diferencias multiplicativas se comportan mejor en esa escala.

            
y_i = log(r_i)

          


          

            
4. Contraccion empirical Bayes

            
El modelo no confia igual en todas las filas. Si hay pocas transacciones o pocos pares comparables, contrae la senal hacia un resultado prudente.

            
mu_i* = w_i y_i + (1 - w_i) mu_0

            
w_i = evidencia_i / (evidencia_i + k)

            
mu_0 representa el comportamiento global esperado, cercano a ratio 1. w_i aumenta cuando hay mas evidencia comparable. Esta idea se apoya en la tradicion empirical Bayes: usar el conjunto de datos para estimar parte del prior y estabilizar estimaciones ruidosas.

          


          

            
5. Probabilidad posterior de precio alto

            
La pregunta operativa del panel es:

            
Probabilidad = P(r_i > 1,5 | datos)

            
Si la probabilidad es alta, el item no se marca como irregular por si mismo; queda priorizado para revisar pliego, especificacion tecnica, alcance, forma de pago, lote, urgencia y evidencia documental.

            
El score combina probabilidad, magnitud del ratio, cantidad de evidencia y advertencias de calidad para ordenar la cola de revision.

          


          

            
6. Intervalo posterior

            
La app muestra un intervalo porque el precio de referencia no es una verdad absoluta. Dos filas con igual ratio pueden tener distinta calidad de evidencia.

            
intervalo = [q_5(r_i | datos), q_95(r_i | datos)]

            
Un intervalo estrecho indica mayor estabilidad de referencia. Un intervalo amplio indica que el usuario debe revisar con mas cautela antes de interpretar la senal.

          


          

            
7. Modelo de concentracion entidad-proveedor

            
Para concentracion se usa un suavizado de participacion. La idea es evitar que una proporcion extrema con muy pocos contratos tenga el mismo peso que una proporcion extrema con mucha evidencia.

            
share_monto = monto_entidad_proveedor / monto_entidad

            
share_suavizado = (monto_entidad_proveedor + alpha) / (monto_entidad + alpha K)

            
Este enfoque es coherente con priors tipo Dirichlet para proporciones: las observaciones se combinan con pseudo-conteos o pseudo-montos para estabilizar participaciones.

Limitaciones y controles de calidad

          

            

              
Lo que el modelo puede hacer

              
    
                
  • Priorizar items que merecen revision humana.
    • 
                
  • Mostrar por que una fila quedo alta: ratio, referencia, probabilidad e intervalo.
    • 
                
  • Separar casos estadisticos de casos con posible problema de dato.
    • 
                
  • Ayudar a detectar patrones repetidos por entidad, proveedor, rubro o unidad.
    • 
              

            

            

              
Lo que el modelo no puede concluir solo

              
    
                
  • No prueba sobreprecio, dolo ni irregularidad administrativa.
    • 
                
  • No reemplaza estudio de mercado ni precio referencial formal.
    • 
                
  • No interpreta automaticamente marcas, modelos, calidad, alcance contractual ni servicios conexos.
    • 
                
  • No corrige por completo errores de catalogo, unidad o descripciones incompletas.
    • 
              

            

          

        


        

          
Bibliografia y referencias usadas como base conceptual

          

            
              Bayes, T. (1763)
              An Essay towards solving a Problem in the Doctrine of Chances.
              Origen historico del razonamiento inverso/probabilidad posterior.
            
            
              Efron, B. y Morris, C. (1972/1973)
              Stein's Estimation Rule and its Competitors - An Empirical Bayes Approach.
              Base conceptual para estabilizar estimaciones con informacion global.
            
            
              Gelman et al.
              Bayesian Data Analysis.
              Referencia moderna para modelado bayesiano aplicado, chequeo e interpretacion.
            
            
              Gelman, Carlin, Stern, Dunson, Vehtari y Rubin (2013)
              Bayesian Data Analysis, 3rd edition.
              Texto aplicado de referencia sobre inferencia, modelos jerarquicos y evaluacion.
            
            
              Robert, C. P. (2007)
              The Bayesian Choice.
              Fundamentos de inferencia bayesiana, decision y extensiones jerarquicas/empirical Bayes.
            
            
              Dirichlet-multinomial
              Modelo para conteos multiclase con sobre-dispersion.
              Motivacion para suavizar participaciones y evitar proporciones extremas sin evidencia suficiente.
